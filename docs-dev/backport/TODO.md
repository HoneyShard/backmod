11. Eighth launch (2026-11-21): no crash and the Jacaranda settings screen opens, but its preview box is empty (the Diamond Sword is not drawn), the same family as the invisible sword. Cause found by diffing `PictureInPictureRenderer.prepareTexturesAndProjection` between the two jars: 26.2 moved the whole renderer to reversed depth. 26.2 clears depth to 0 (26.1.2: 1.0), `DepthStencilState.DEFAULT` is `GREATER_THAN_OR_EQUAL` (26.1.2: `LESS_THAN_OR_EQUAL`), and vanilla's pipelines use `GREATER_THAN_OR_EQUAL` 14 times where 26.1.2 uses `LESS_THAN_OR_EQUAL` 15 times. - 26.3 moved `RenderPipeline` to `com.mojang.renderpearl.api.pipeline`. The shims are 26.1.2 only, which is Backmod's only target.
